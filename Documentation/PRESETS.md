# VisualFX Presets

> Generated by `tools/gen_docs.sh`. Resolved configurations for every preset: `schema/presets.json`.

Presets are plain configuration data stored as ModuleScripts in
`Presets/BuiltIn` (read-only) and `Presets/User`, or saved at runtime with
`VisualFX:SavePreset` (persisted through a storage adapter; the Studio plugin
uses `plugin:SetSetting`).

```lua
VisualFX:ApplyPreset("CinematicSunset")                        -- replace the managed scene
VisualFX:ApplyPreset("LightRain", { Merge = true })            -- merge into the current scene
VisualFX:ApplyPreset("Night", { Transition = { Duration = 6 } })
VisualFX:ApplyPreset("Storm", { Overrides = { Weather = { Intensity = 1 } } })
VisualFX:SavePreset("MyEnvironment", VisualFX:ExportConfiguration())
VisualFX:DeletePreset("MyEnvironment")
```

## Composition

`Inherits` lists presets merged **left to right**, then the preset's own
values are merged last (dictionaries merge recursively, scalars/arrays
replace, `"$remove"` deletes). `Metadata` is never inherited. Missing parents
and cycles are validation errors.

```text
BaseForest + Autumn + LightRain = AutumnRainForest
```

```lua
return {
    Version = 1,
    Metadata = { Name = "Autumn Rain Forest", Category = "Forest" },
    Inherits = { "BaseForest", "Autumn", "LightRain" },
    Weather = { Intensity = 0.55 },
}
```

Compose on the fly with `VisualFX:ComposePresets({ "BaseForest", "Autumn", "LightRain" }, overrides)`.

## Writing a preset

```lua
-- Presets/User/MistyForest.luau (or save with VisualFX:SavePreset)
return {
    Version = 1,
    Metadata = { Name = "Misty Forest", Category = "Forest" },
    Atmosphere = {
        Density = 0.45,
        Haze = 2.5,
        Glare = 0,
        Color = Color3.fromRGB(170, 190, 175),
        Decay = Color3.fromRGB(90, 110, 100),
    },
    Lighting = { ClockTime = 8, Brightness = 1.5, ExposureCompensation = 0 },
    Weather = { Type = "Fog", Intensity = 0.6 },
}
```

Presets are validated when applied or saved, so a broken preset never
partially applies.
